# Swiggy-Sql-Case-Study
SQL-based analysis of Swiggy food delivery data to uncover customer behavior, restaurant performance, sales trends, revenue growth, and business insights through real-world analytical queries.

# Skills Demonstrated

- SQL Joins
- Aggregate Functions
- Group By & Having
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- Business Analytics
- Customer Segmentation
- Revenue Analysis


# Business Questions Answered

1. Find customers who have never placed an order.
2. Calculate the average price per dish.
3. Identify the top-performing restaurant based on order volume for a given month.
4. Find restaurants with monthly sales above a specified threshold.
5. Retrieve complete order details for a customer within a given date range.
6. Identify restaurants with the highest number of repeat customers.
7. Analyze month-over-month revenue growth.
8. Determine each customer's favorite food item.
9. Identify the most loyal customers for each restaurant.
10. Analyze month-over-month revenue growth of a particular restaurant
11. Discover the most frequently paired products.

# Dataset
The dataset contains information about users, restaurants, orders, menu, food items, and order details

## Files

- `queries.sql` : Contains all SQL solutions.
